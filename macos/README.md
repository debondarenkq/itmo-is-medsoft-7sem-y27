# HIS для macOS

Нативное приложение на Swift 6 и SwiftUI для macOS 14 и новее. Использует системные таблицы, формы, боковую панель, кнопки, меню, выбор файла и светлую/тёмную тему. Внешних UI-библиотек и собственных стилей элементов управления нет.

## Запуск

Нужны Xcode 16+ с принятыми условиями лицензии Apple SDK и работающий backend.

Из корня репозитория:

```sh
make up
make macos-build
open macos/build/HIS.app
```

Сборка использует цель macOS Application в `HIS.xcodeproj`. API-клиент подключён как локальный Swift-пакет `Generated`; сетевых зависимостей нет. `build.sh` вызывает `xcodebuild` и копирует подписанную локальной ad hoc подписью `.app` в `build/HIS.app`. Для распространения за пределами учебного окружения нужны Developer ID и notarization; CI-артефакт не нотарифицирован.

## Запуск из Xcode

1. Откройте `macos/HIS.xcodeproj`.
2. Вверху выберите схему **HIS** и устройство **My Mac**.
3. Нажмите **▶ Run** или **⌘R**. Xcode соберёт и запустит `HIS.app`; Apple Developer Team для локальной сборки не требуется.

В меню **HIS → Настройки…** (`⌘,`) задаётся адрес Nginx, по умолчанию `http://localhost:8080`. Он сохраняется между запусками. HTTP разрешён для учебного backend; запросы к сервисам идут через gateway.

## Работа

- Внизу боковой панели выбирается профиль: администратор или активный медработник из серверного списка. Паролей и аутентификации нет. Администратор видит сотрудников и диагнозы, медработник — пациентов. Профиль можно сменить там же; смена сервера сбрасывает выбор.
- Списки поддерживают поиск на сервере, пагинацию и обновление. Выбор строки открывает действия панели инструментов, двойной щелчок — карточку пациента либо редактор справочника.
- Формы используют стандартные поля и календарь macOS. Сервер проверяет бизнес-ограничения и возвращает сообщения, включая ошибки отдельных полей.
- Импорт диагнозов открывает системный диалог JSON. Файл отправляется целиком без локального разбора. Пример: `examples/diagnoses.json`.
- ЭМК открывается кнопкой в списке пациентов. Автор создания и изменений — выбранный профиль медработника. Разблокировка требует явного подтверждения.
- В карточке пациента доступны просмотр данных, редактирование, переход к ЭМК и удаление.
- Таблица диагнозов ЭМК показывает дату, статус и удалённые записи из истории, позволяет удалить и восстановить диагноз.
- Диагнозы и назначения редактируются в черновике. Сохранение отправляет все команды с исходной версией карты одним запросом. `⌘S` сохраняет черновик.
- Отмена, обновление и закрытие карты с изменениями требуют подтверждения. Ошибка сервера или конфликт версии сохраняют черновик.
- История показывает автора, время, снимки до/после. Можно открыть состояние на версию или выбранную дату и время; оно доступно только для просмотра.

## Структура

- `Sources/HIS/App` — приложение, навигация и настройки.
- `Sources/HIS/Staff`, `Diagnoses`, `Patients`, `Records` — экраны по предметным областям.
- `Sources/HIS/Shared` — общие элементы отображения, выбор справочника и подключение.
- `api` — объединённая OpenAPI-спецификация и конфигурация генератора.
- `Generated` — Swift 6 HTTP-клиент и Codable DTO из общих контрактов; вручную не редактируется.
- `Resources` — Info.plist и иконка.
- `HIS.xcodeproj` — цель macOS Application и общая схема HIS для запуска и отладки.

Генерация: `make generate-contracts` из корня. Новые тесты не добавлены. Workflow macOS компилирует приложение и публикует `.app` в ZIP.

Предыдущая реализация на Flutter сохранена отдельно в `desktop/` для сравнения. Она не участвует в сборке Swift-приложения и больше не является основным клиентом.
